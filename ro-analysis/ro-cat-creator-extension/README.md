# RO 创建猫角色插件（lastro api.html）

游戏「角色选择页」左下角悬浮面板，一键创建猫角色（召唤师 job=4218），可切人类初心者。

## 安装

1. Chrome 打开 `chrome://extensions` → 右上角开「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本目录（ro-cat-creator-extension）
3. 打开游戏页（post.lastro.cn / game.lastro.cn 的 `/ro/api.html`），登录到**角色选择页**

## 使用

- 面板显示「角色服已连接 ✓（N/M 槽）」即可用；进图后自动失效（回到角色选择页自动恢复）
- 名字默认随机（Mao+6 位 / Ro+6 位），可自行修改，**仅支持英文/数字/符号**（服务器中文名是 GBK 编码，输入框输入中文会乱码，已拦截）
- 点「🐱 创建猫角色」→ 自动选最小空闲槽位发送建角封包 → 等服务器重推角色表
- 面板显示「✅ 创建成功：xxx（slot N）已出现在角色表」即完成，游戏角色页会同步刷新出新生
- 连点保护 8s（等服务器确认期间按钮禁用）

## 原理与真值（2026-09-22 定稿）

- 建角封包：`CH.MAKE_CHAR3 0x0A39`（36B）= pid u16 + name[24] + slot u8 + headPal u16 + head u16 + job u16 + unknown u16 + sex u8；
  job=4218 召唤师(猫)/0 人类；head=1（0=无头贴图）、headPal=0、sex=1 —— 与 leveler.js 建猫参数一致（生产验证）
- 注入通道：char 连接（角色服 WebSocket）。**浏览器 OUT 方向为明文**（wslog 抓包实证 0x0065/0x0066 直读），
  不同于 zone 连接的 LCG 流式加密 → 明文注入无密钥流错位/踢线风险，也无需等加密收敛
- 成功判定：服务器建角后重推 `0x006B` 角色表，新名字出现在表里 = 成功（leveler 同判法）
- 角色表解析（wslog 实拍验证）：连接首个包前有 4B AID 回声（丢弃）；`0x082D`(29B) 槽位头包 byte@4=总槽数；
  `0x006B` 长度取 u16@2，175B 角色块起点 +27（探测窗口 17..33），块内 name@108(24B GBK)、slot@138、job@84、level@92
- 插件 `document_start` + MAIN 世界注入，抢在游戏建 WebSocket 之前挂钩子

## 排查

- 面板一直「未检测到角色服」：刷新游戏页再进角色选择（钩子必须在连接建立前就位，插件刚装时旧页面没钩子）
- 点了创建但 8s 后「未见新角色」：多为名称被占，换 ↻ 随机名重试
- 控制台可查状态：`__catCreatorDebug.st`（角色表/连接）；手动喂包测试：`__catCreatorDebug.parseCharList(u8arr)`
